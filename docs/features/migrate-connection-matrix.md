# /migrate — connection-mode matrix

Five ways to be connected to gnars.com, four money-moving actions. Each cell says
whether it works, how it degrades, and **how that was verified** — not assumed.
Verification legend: **runtime** = rendered and driven in the browser with
`scripts/pw-migrate-connected.ts` (read-only impersonated wallet, real Base data
or the Anvil fork); **fork** = executed on an Anvil fork of Base against the
live UpgraderEth (`scripts/sim-migrate-batch.ts`); **test** = unit test;
**code** = read the code path, not executed; **checklist** = needs a human with
a wallet, see `migrate-runtime-checklist.md`.

Quote sources: Zora first; KyberSwap when Zora fails or has no route (the only public aggregator that routes Zora's v4 hook pools — probed against eight sources on 2026-09-02). Both execute in both modes; Kyber needs no Permit2 signature.

Invariant that must never break: the `user` argument of `deposit` /
`withdraw` / `claim` is always the address that signs (`writer.account.address`
from `useWriteAccount`), never `saAddress`/`adminAddress` picked by hand.
`src/lib/upgrader-calls.ts` is the only place the calls are built, and its test
pins the calldata against the contract's own ABI.

## What the matrix says in one paragraph

The batch path (one signature, nothing passing through the wallet) exists only
for accounts whose assets sit in the smart account — in practice the in-app
wallet. Every external wallet holds its coins in the EOA, so its real path is
sequential in EOA mode; SA mode shows an honest empty list rather than a broken
batch. The mini app is sequential by construction. Withdraw and claim must be
signed by the address that deposited; the terminal reads both addresses when a
wallet has two and says which mode to use, so a deposit never looks lost.

## Still only on the checklist

Every click that moves value (a real sell, deposit, withdraw) and the two
sessions that cannot be impersonated read-only (in-app OTP login, the Warpcast
host). Nothing in those cells is assumed to work; they are marked for a human.
